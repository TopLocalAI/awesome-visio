# Contribution Guidelines

Thanks for helping improve Awesome Visio. By contributing, you agree that your contribution is released under [CC0-1.0](LICENSE).

## What belongs here

- Resources about Microsoft Visio, the `.vsdx` / `.vsd` / `.vdx` / `.vssx` file formats, or a working route into or out of them.
- Tools must exist and work today. We open every link before merging, and for GitHub projects we check activity.
- Archived or inactive projects are only kept when they are still useful or historically important, and are marked "Inactive" or "Unmaintained".
- Paid products are welcome when they genuinely handle Visio files. Mark them 💲.
- Tools made by the list maintainers are marked ⭐ and follow exactly the same format and criteria as everything else.

## Entry format

```md
- [Name](https://link) - Short description.
```

- Search the list first to avoid duplicates. Each link may appear only once.
- Put the entry in the most fitting section. If no section fits, propose one in your PR.
- The description starts with a capital letter, ends with a period and stays under about 25 words.
- Say what it does, not how great it is. No marketing superlatives or prices.
- Note when a tool needs Visio installed or only runs on Windows, e.g. "Needs Windows and Visio."
- Link to the canonical page (official site or repository), not to a blog post about it.

## Pull requests

- One entry per pull request is easiest to review.
- Update both `README.md` and `README.zh-CN.md` if you can. If you can't, a maintainer will add the translation.
- Run `npx awesome-lint` before submitting.

## Updating or removing entries

Open a PR or an issue if a link is broken, a project is abandoned, or a description is no longer accurate.
