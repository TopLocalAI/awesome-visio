# Contribution Guidelines

Thanks for helping improve Awesome Visio. By contributing, you agree that your contribution is released under [CC0-1.0](LICENSE).

## Adding an entry

- Make sure the resource is about Microsoft Visio, the `.vsdx` / `.vsd` file formats, or a route into or out of them.
- Search the list first to avoid duplicates.
- Put it in the most fitting section. If no section fits, propose a new one in your PR.
- Use this format: `- [Name](https://link) - Short description.`
  - The description starts with a capital letter, ends with a period and stays under about 20 words.
  - Say what it does, not how great it is. No marketing superlatives.
  - Add 💲 to commercial or paid-only products.
- Link to the project's canonical page (official site or repository), not to a blog post about it.
- Check that the link works. For GitHub projects, prefer ones that are maintained, and say so if a project is archived or inactive.
- One entry per pull request is easiest to review. Update both `README.md` and `README.zh-CN.md` if you can. If you can't, a maintainer will add the translation.

## Updating or removing entries

Open a PR or an issue if a link is broken, a project is abandoned, or a description is no longer accurate.

## Disclosure

If you are affiliated with the tool you are adding, say so in the PR description. The maintainers (TopLocalAI) list their own products only in the clearly labeled "Featured" section.
